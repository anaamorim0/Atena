# Atena
Experimental app to improve skills in computer science and web development.

## First Steps
The project was created using Vite:
```npm create vite@latest```
We got this initial project structure:
```
atena-app
├── index.html
├── package.json
├── vite.config.js
│
└── src
    ├── main.jsx
    ├── App.jsx
    └── style.css
```
